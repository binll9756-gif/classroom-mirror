# 第一部分 · FIAS 编码规则卡

## 1.1 编码体系（九类）

依据弗兰德斯互动分析系统（FIAS），本系统对**每一句课堂话语**打一个标签。第 1~4 类为教师的"间接影响"，第 5~7 类为"直接影响"，第 8~9 类为学生话语。

| 编码 | 类别 | 中文名 | 判定要点 | 例句 |
|---|---|---|---|---|
| **1** | 教师·间接影响 | 接受情感 | 对学生**情绪**的接纳与共情，不评价对错 | "看得出这道题让你有点挫败，没关系" |
| **2** | 教师·间接影响 | 表扬鼓励 | 明确的正向评价或鼓励 | "很好！思路很清楚""你能主动想到这一步很棒" |
| **3** | 教师·间接影响 | 采纳想法 | 复述/引用/延展**学生的想法**（把话语权还给学生的关键行为） | "你刚才说'先看符号'，我们就按你的思路来" |
| **4** | 教师·间接影响 | 提问 | 向学生提问（含点名） | "谁能说说为什么？""小林，你试试" |
| **5** | 教师·直接影响 | 讲授 | 陈述知识、解释、举例、演示、总结 | "负负得正的意思是……" |
| **6** | 教师·直接影响 | 给出指令 | 指挥学生行为、布置任务、进度安排 | "把书翻到第 30 页""大家记住，考试要考" |
| **7** | 教师·直接影响 | 批评 | 否定、斥责、纠正态度（含隐含的否定） | "这么简单都不会？""你又走神了" |
| **8** | 学生 | 应答 | 学生**被教师提问后**作答 | "老师，答案是正三" |
| **9** | 学生 | 主动发起 | 学生**未被提问**而自发发言、提问、质疑 | "老师，那如果除数是零呢？" |

## 1.2 指标计算（**由代码计算，不由 LLM 计算**）

| 指标 | 公式 | 含义 |
|---|---|---|
| **TT** 教师话语比 | (第1~7类计数) / 全部计数 | 教师占用了多少话语 |
| **ST** 学生话语比 | (第8~9类计数) / 全部计数 | 学生占用了多少话语 |
| **IDR** 间接/直接影响比 | (第1~4类计数) / (第5~7类计数) | 🔥 **核心指标**：教师是"引导"还是"灌输" |
| **SIR** 学生主动发起比 | 第9类 / (第8类+第9类) | 学生是"被点名"还是"自己想说" |

**对照刻度（引自 SimClass 论文 Table 2，NAACL 2025）**

| 对象 | TT | ST | **IDR** | SIR |
|---|---|---|---|---|
| **专家人类教师** | 0.771 | 0.229 | **1.473** | 0.121 |
| **新手人类教师** | 0.826 | 0.174 | **0.885** | 0.106 |
| AI 教师（多智能体课堂） | 0.816 | 0.184 | **0.058** | 0.896 |

> **报告里必须画出这三条参照线**。这是本系统区别于"AI 随便给个评分"的关键：**我们的指标有学界公认的对照基准。**

## 1.3 易混淆边界（给 LLM 的硬规则 + 给人工标注者的说明）

| 情形 | 正确编码 | 说明 |
|---|---|---|
| "大家记住，考试要考" | **6 给出指令** | **不是 5 讲授**。这是典型的"用考试压力替代原理解释"，是最值得被指出的行为之一 |
| "嗯。"（学生答完后仅示意继续） | **3 采纳想法** | 不是 2 表扬（无正向评价） |
| "很好，说得对，那我们看下一题" | **2 表扬鼓励**（主导行为） | 若表扬后立刻转入讲授，表扬仍单独记 2，后续记 5 |
| "我们来看看这道题" | **5 讲授** | 若句式是"谁会做这道题？"则记 **4 提问** |
| 教师**自问自答**（提问后 <1.5 秒自己说出答案） | 记 **4 提问**，且**不产生 8/9 类**；同时计入「**抢答率**」 | 这是"等待时间"训练的核心数据：**它既暴露了提问，也暴露了没等** |
| 学生被点名后回答 | **8 应答** | — |
| 学生追问"为什么" | **9 主动发起** | 即使紧跟在教师提问之后，只要是**未被要求**的追问，仍记 9 |
| 一个句子同时含表扬与提问 | **按主导意图记一类**，并在备注保留原句 | 例如"很好！那谁能说说为什么？"→ 记 **4 提问**，备注含表扬 |
| 教师沉默、学生沉默 | **不编为第 10 类** | 原版 FIAS 有"沉默/混乱"类，但多智能体课堂研究中因其"难以定义与检测"而被排除。本系统同样**把沉默单列为独立事件类型**（`event.type = silence`），用于计算等待时间，不进入九类计数 |

## 1.4 附加指标（本系统的教学价值所在，均从事件流派生）

| 指标 | 定义 | 为什么重要 |
|---|---|---|
| **平均等待时间** | 提问结束 → 教师点名/自答 的间隔均值（秒） | 教育学经典：等待时间延长至约 3 秒，学生回答长度与质量显著改善 |
| **抢答率** | 提问后 <1.5 秒即自答的占比 | 直接对应"没等"的行为 |
| **记忆型提问占比** | 布鲁姆认知层次为"记忆"的提问 / 全部提问 | 目标写"理解/应用"，提问却全是"记住了吗"，即评价层次低于目标 |
| **叫答覆盖度** | 被叫答过的学生数 / 学生总数 | 课堂参与公平性 |
| **被忽略学生数** | 整节课 0 次被叫答的学生数 | 师德与教育公平；**演示时视觉冲击力最强的一项** |
| **对齐矩阵完整度** | 有活动且有评价对应的目标数 / 目标总数 | 建构一致性 |

## 1.5 ⚠️ 指标有效性辨析：哪个指标**真正**反映师范生的能力

> 这一节很重要，**如果搞错，说明书会被评审当场问倒**。请务必读完再写"成效"章节。

FIAS 的四个指标并非同等可用。区别在于：**有些指标是我们自己设定的，有些才是师范生的行为。**

| 指标 | 是否纯粹反映师范生能力 | 原因 |
|---|---|---|
| **IDR** | ✅ **是（最干净）** | 它在**教师自己的话语内部**做分母分子（第1~4类 ÷ 第5~7类），**与"学生说了多少话"完全无关**。它只回答一个问题：这位教师在自己开口时，选择"引导"还是"灌输" |
| **等待时间 / 抢答率** | ✅ 是 | 完全由教师行为决定（问完等多久） |
| **记忆型提问占比 / 提问层次分布** | ✅ 是 | 完全由教师的提问设计决定 |
| **叫答覆盖度 / 被忽略学生数** | ✅ 是 | 完全由教师的点名行为决定 |
| **对齐矩阵完整度** | ✅ 是 | 由教案与实施的一致性决定 |
| **TT / ST** | ⚠️ **部分是** | 学生说了多少，很大程度取决于**我们设定的学生参与度**。教师少说话可能只是"学生被设定得更爱说" |
| **SIR 学生主动发起比** | ❌ **基本不是** | 在我们的系统里，"学生"是 AI，**主动发起的比例是我们设计出来的参数**（参与度 0.3 还是 0.8 由我们决定）。把它当作师范生的能力指标是**逻辑错误** |

### 由此得出的三条使用纪律

1. **成效验证的主指标只能是"教师纯行为指标"**：**IDR** + 等待时间 + 抢答率 + 记忆型提问占比 + 叫答覆盖度 + 被忽略学生数 + 对齐完整度。
2. **TT / ST / SIR 只作为"课堂情境描述"报告**，用于解释（"这节课教师话语占比 78%，学生发言集中在两位"），**不得作为"师范生能力提升"的证据**。
3. **两轮试讲必须使用相同的学生原型与参与度配置**（见文件 08 的 3.2 关键控制），否则 TT/ST 的变化无法解释。

### 顺带解释一个容易误读的数字

SimClass 论文中 AI 课堂的 **SIR = 0.896**（远高于专家教师的 0.121）——**这看起来像"AI 的学生比真人学生更主动"，但那是因为 AI 学生的主动发言是设计出来的**，不代表教学更成功。**引用这个数字时务必说明这一点**，否则会显得我们没读懂文献。

### 结论：旗舰指标只有一个

> **IDR 是本系统唯一"既纯粹反映教师行为、又有学界公认基线可对照"的指标。**
> 专家人类教师 1.473 ｜ 新手人类教师 0.885 ｜ AI 教师 0.058。
> **报告与答辩的第一句话应该是："我们测的是 IDR——因为它只跟老师自己有关。"**

# 第二部分 · 初中数学迷思概念库（初稿）

## 2.1 使用方式

- **A2 虚拟学生铸造工坊**从中选取（按教案的知识点匹配），生成学生的"预设错误"；
- **A4 虚拟学生**的错误必须**源自这里**，且**答错后至少坚持一轮**（不自行"变聪明"）；
- **A6 评价员**用它判断"教师是否识别并处理了该错误"；
- 建议每条记录包含：`id / 学段 / 知识点 / 迷思概念 / 学生典型说法 / 诊断线索 / 教学应对`。

> ⚠️ **MVP 只需 5~8 条**（对应"负负得正"课时）。以下是可用的种子库，**必须经数学教育方向教师审阅后定稿**。

## 2.2 种子库

### A. 有理数与运算（**七年级上，MVP 首选**）

| id | 迷思概念 | 学生典型说法 | 诊断线索（哪个提问能暴露它） | 教学应对方向 |
|---|---|---|---|---|
| M-01 | **把"负负得正"当口诀硬背**，不能解释算理 | "老师说的，两个负号就变正号" | "为什么两个负数相乘会得正数？能不能举个例子说明？" | 用相反数意义/数轴或实际情境（如连续两次反向行走）建立意义 |
| M-02 | **绝对值等于"去掉负号"** | "-5 的绝对值是 5，就是把负号划掉" | "｜a｜ 是什么意思？如果 a 是负数呢？" | 回到"到原点的距离"，强调距离非负 |
| M-03 | **负数比大小按数字大小比** | "-3 比 -5 小" | "在数轴上 -3 和 -5 谁在右边？" | 用数轴位置关系重建 |
| M-04 | **减法一律"大减小"** | "3-7 不够减，所以是 7-3=4" | "3-7 等于多少？为什么？" | 用数轴方向或温度变化解释 |
| M-05 | **运算顺序随意** | "-2² 和 (-2)² 一样" | "-2² 等于多少？(-2)² 呢？两者为什么不同？" | 明确"幂的底数是谁" |
| M-06 | **有理数加法只看绝对值** | "-3+5=-8，因为 3+5=8" | "异号两数相加，结果符号由谁决定？" | 用"抵消/欠账"情境重建 |

### B. 代数式与方程（七至八年级）

| id | 迷思概念 | 学生典型说法 | 诊断线索 | 教学应对方向 |
|---|---|---|---|---|
| M-07 | **合并同类项时把指数也相加** | "2x+3x=5x²" | "2x 和 3x 相加，为什么不是 5x²？x 代表什么？" | 回到"x 是同一个数"，用具体数值验证 |
| M-08 | **去括号时负号只作用于第一项** | "-(a+b)=-a+b" | "如果 a=1,b=2，代进去算算两边相等吗？" | 用分配律或数值检验 |
| M-09 | **移项不变号** | "x+3=5，所以 x=5+3" | "为什么移过去要变号？能不能用等式性质说明？" | 回到等式两边同减同加的性质 |
| M-10 | **方程与恒等式混淆** | "这个式子有 x，就是方程，能解出 x" | "2(x+1)=2x+2 有唯一解吗？" | 区分"解"与"恒成立" |
| M-11 | **分式方程不检验增根** | "解出来 x=2，答案就是 2" | "把 x=2 代回原方程，分母是多少？" | 强调"分母不为零"是前置条件 |
| M-12 | **因式分解不彻底** | "x²-4=(x-2)(x+2)…也可以是别的" / 停在 x⁴-1=(x²-1)(x²+1) | "还能继续分解吗？" | 强调分解到不能再分 |

### C. 函数与图像（八至九年级）

| id | 迷思概念 | 学生典型说法 | 诊断线索 | 教学应对方向 |
|---|---|---|---|---|
| M-13 | **把函数等同于"公式"** | "有公式才是函数" | "这张气温变化图是函数关系吗？" | 回到"一个 x 对应唯一 y"的对应关系 |
| M-14 | **误解一次函数 k 的意义** | "k 是几就是几倍" | "k>0 和 k<0 时图像有什么不同？" | 用增减性与图像走向建立联系 |
| M-15 | **相似比与面积比混淆** | "相似比 1:2，所以面积比也是 1:2" | "两个相似三角形，边长都扩大 2 倍，面积扩大几倍？" | 用具体图形分割验证 |

### D. 几何、统计与概率

| id | 迷思概念 | 学生典型说法 | 诊断线索 | 教学应对方向 |
|---|---|---|---|---|
| M-16 | **π 当作精确值 3.14** | "π 就是 3.14" | "π 是无限不循环小数，那 3.14 和 π 相等吗？" | 强调近似值概念 |
| M-17 | **忽略等可能前提谈概率** | "买彩票不是中就是不中，各一半" | "中奖和不中奖这两种结果，可能性真的一样吗？" | 明确等可能性的前提条件 |
| M-18 | **平均数代表全体** | "我们班平均分 80，所以大家都考了 80 左右" | "如果有一个同学考了 0 分，平均数会怎样变化？" | 用极端值演示平均数的敏感性 |
| M-19 | **全等与相似混淆** | "形状一样就是全等" | "两个形状相同但大小不同的三角形，是全等吗？" | 区分形状与大小两个维度 |
| M-20 | **三角形外角等于任意两内角和** | "外角等于另外两个角相加" | "外角等于的是哪两个角的和？要不要'不相邻'？" | 强调"不相邻"这一限定条件 |

## 2.3 每条迷思概念的机器可读格式（A2 直接消费）

```yaml
  teaching_move: 用相反数意义或实际情境建立意义
  subject_teacher_reviewed: false   # ⚠️ 审核后置 true
```
